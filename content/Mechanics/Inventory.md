# Inventory
- Inventory and UI are minimalist
- only a 10 item hotbar for medicine, weapons, etc.
- [resources](Materials.md) are stored as numerical values
- [magazines](Ammo.md) are not stored either, they only exist as small icons in the bottom right
	- on mouse hover, show details
	- click to reload or use normal reloading methods
