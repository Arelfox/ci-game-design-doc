# Inventory
- grid based
- effectively unlimited capacity (player should not have to drop something to make room)
- some items can stack, up to 64
## Equipment Slots
- primary
- secondary
- melee
- armor
- shield
## Interaction
- drag/drop
- stack splitting (rmb)
- dropping
- pickup
## Magazines
- dragging ammo into mag fills it with only that
- dragging another type of ammo into a **full** mag fills it with half the current and half the new ammo
- dragging another type of ammo into an **partial** mag fills it with the ammo selected until full or the stack runs out
- there is also an option to mix up the ammo in a mag
