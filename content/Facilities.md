# Objectives
Different facilities (missions) have different objectives and environments that change how a player will prepare:
- ## Environments:
	- Industrial
		- More metal and alloy
		- Printers are more common
	- Chemical
		- More chemicals
		- Hazardous rooms
- ## Objectives
	- set extraction time
		- there is only 1 extraction opprotunity and your goal is to get as much stuff in that window
		- should be short but long enough to at least mostly complete a build by the end
	- resource objective
		- command needs you to get x amount of this material, only when you get it you can extract when ready
		- probably better to use a material which isnt rewarded, or maybe only leave 25% for the player to keep
	- kill objective
		- objective is to disrupt operation of the facility, resources is secondary
	- story missions
		- some sort of lore
		- completion reward, not necessarily resource reward

- harder missions can have oppressive enemies, but easier missions should be relatively common to get op builds
	- facility difficulty should still escalate in the run
	- ideal run difficulty (relative to player gear) for a somewhat experienced player on easy:
		- easy --> normal --> easy --> hard
		- extraction should feel like a relief, but you should also be able to feel op with a complete build at some point
